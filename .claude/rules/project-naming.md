# Project Naming

- The product's name is **Music Transpose**. "Ascurix" and "Doron Desktop" are prior names.
- When referring to the project in conversation, docs, comments, UI copy, or any other non-resource context, use **Music Transpose**.
- Exception: real, physical resources that were provisioned under an old name — the GitHub repo, the local directory path, package names, app identifiers (e.g. `com.tsemach.doron-desktop`), the Cargo crate (`ascurix`), the `ascurix.settings` localStorage key, etc. — keep their current names until they are manually migrated. Do not rename these on your own initiative.
